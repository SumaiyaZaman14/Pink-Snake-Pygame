# 🐍 Pink Snake

A simple Snake game made with **Python and Pygame**.

## Features

- 🩷 Baby pink background
- 🐍 Green snake
- 🪙 Coins for points
- 🧱 Obstacles
- 💥 Collision detection
- 📈 Increasing game speed
- 🔄 Restart after Game Over

## Controls

- **Arrow Keys / WASD** — Move
- **R** — Restart after Game Over

## Run

```bash
pip install pygame
python game.py
```
